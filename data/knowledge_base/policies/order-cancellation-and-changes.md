# Order Cancellation and Changes

## Cancelling an order
You can cancel an order at any time **before it ships** (statuses: pending, paid, processing). Cancellation is instant.
- If payment was already captured, a **full refund** is issued to the original payment method and normally appears within 3–5 business days.
- Pending orders have not been charged, so nothing is refunded.
Once an order has **shipped it can no longer be cancelled**. Wait for delivery and start a return instead — or refuse the delivery, in which case the refund is issued when the parcel returns to us.

## Changing the shipping address
The shipping address can be changed until the order ships. After shipment, address changes must be requested directly from the carrier using the tracking number; we cannot guarantee them.

## Changing items
Items cannot be added to or removed from an existing order. Cancel the order (if it hasn't shipped) and place a new one.

## Changing the payment method on an order
You can switch to another saved card while the order is **pending or paid**. Once the order is being processed the payment is locked.
